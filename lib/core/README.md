# lib/core/

## Purpose
Contains shared utilities, constants, theme configurations, and custom error definitions used across the entire application.

## Subdirectories
- `constants/`: Global app values, API paths, and storage keys.
- `theme/`: Material 3 theme configuration, color tokens, and text styling.
- `utils/`: Reusable validation, date formatting, and logging utilities.
- `errors/`: Typed application exceptions for structured error handling.
