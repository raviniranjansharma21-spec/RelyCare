# lib/app/

## Purpose
This folder contains application-level configuration, startup setup, routing, and global settings.

## Files
- `app.dart`: The root `MaterialApp` widget for RelyCare. Configures themes, titles, and routing.
- `routes.dart`: Declares all named routes and maps them to screen widgets.
- `app_config.dart`: Stores environment constants, configuration flags, and feature toggles.
