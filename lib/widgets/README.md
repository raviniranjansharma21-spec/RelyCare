# lib/widgets/

## Purpose
Contains modular, reusable UI components shared across multiple screens.

## Files
- `referral_card.dart`: Summary card for displaying referral info in feeds and lists.
- `referral_status_chip.dart`: Visual badge reflecting the current referral lifecycle state.
- `connectivity_indicator.dart`: Indicator showing network connectivity status (Online / Offline).
- `sync_status_indicator.dart`: Indicator showing background synchronization progress.
- `confidence_badge.dart`: Visual chip displaying matching confidence score (High/Medium/Low).
- `patient_info_card.dart`: Compact card displaying patient demographics.
- `primary_button.dart`: Standardized action button supporting loading and disabled states.
